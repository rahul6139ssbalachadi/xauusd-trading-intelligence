STEP 4: BUILD FLUTTER .EXE
=======================================================

1. Enable Developer Mode:
   Settings → Privacy & security → For developers → Developer Mode ON
   OR run as Admin: D:\rahul_ai\trading\enable_dev_mode.bat

2. Install Visual Studio C++ workload:
   Open Visual Studio Installer → Modify BuildTools 2022
   → Check "Desktop development with C++" → Modify (~20 min download)

3. Build:
   cd D:\rahul_ai\trading\mobile
   flutter build windows --release
   Output: build\windows\runner\Release\trading_app.exe
